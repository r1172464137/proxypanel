## 1. 术语与范围

| 术语 | 定义（产品语义） |
| --- | --- |
| 服务器 | 机器档案：地址、地区、备注、到期日、可选成本、关联 Agent |
| Agent | 某服务器上的管理进程，独立身份与凭据；心跳、拉取授权快照、应用并回执 |
| 核心运行实例 | 可独立启动/停止/回滚的核心进程，每次启动产生新的**运行世代** |
| 节点 | 一个代理入口：监听、对外地址、协议、传输、安全参数 |
| 节点组 | 资源组织单位，可被多个订阅引用；输出时按节点去重 |
| 订阅 | 授权规则集合：节点组、每人配额、周期/时区、默认有效期、客户端模板、使用限制 |
| 成员绑定 | 成员当前唯一主订阅 + 实际有效期 + 允许字段的个人覆盖 + 迁移历史 |
| 订阅链接 | 成员下载配置的个人访问凭据（可撤销，不等于代理凭据） |
| 代理凭据 | 成员×节点维度凭据；统计以稳定 成员ID/节点ID 为键，不以可轮换 UUID 为业务主键 |
| 周期 | 成员持久化的当前计费区间 `[start, end)`，UTC 存储、按业务时区计算 |
| 授权快照 | 面板计算出的“某 Agent 应生效的权限集合”，带单调版本 |
| 应用回执 | Agent 对某个授权/配置版本的**真实执行结果**，与“规则已提交”是两件事 |
| 权限判定 | 计划 `§2.1` 的合取判定，面板、订阅输出、Agent 快照共用同一实现与版本 |

范围排除见计划 `§1.3`，本文不再重复论证；本文不新增任何被排除功能。

## 2. 角色与可见范围

| 能力 | 管理员 | 普通成员 |
| --- | --- | --- |
| 服务器/Agent/核心实例/节点/节点组 | 全部读写 | 不可见（仅见自身授权节点摘要） |
| 订阅规则（含组、配额、周期、模板） | 全部读写 | 不可见规则原值，只可见“实际生效值 + 来源说明” |
| 成员 | 创建、邀请、启停、重置密码、撤销会话、绑定/切换订阅、覆盖、轮换凭据 | 仅本人：改密码、轮换自己的订阅令牌/代理凭据、查看用量 |
| 批量操作与预览 | 可用 | 不可用 |
| 用量 | 全站/按成员/按节点/按周期 | 仅本人（含上/下行、额度、重置时间、超额原因） |
| 事件、任务与同步结果 | 全部 | 仅与自身相关的事件摘要（如“代理访问已暂停”） |
| 设置 | 全部 | 无 |
| 敏感明文 | 不默认展示他人代理凭据明文；仅在明确“重置/查看一次”动作下展示并审计 | 可查看/复制本人订阅链接与本人凭据 |

- 前端隐藏不是安全控制：所有读写权限由后端判定（计划 `§3 F12`）。
- 管理员的“查看他人数据”同样走独立接口权限，不能借用成员接口越权（计划 `§3 F01`）。

## 3. 全局交互规则

| 规则 | 要求 |
| --- | --- |
| 时间显示 | 存储与接口为 UTC（RFC 3339）；界面按**业务时区**显示并标注时区（如 `2026-11-01 00:00 (Asia/Shanghai)`），悬停显示 UTC |
| 单位 | 流量统一按字节存储、按 GiB/GB 展示并显式标注基数；与计划 `§3 F08` 计数口径一致 |
| “规则已保存” ≠ “节点已生效” | 提交成功提示必须写明：业务规则已提交；节点分发为异步，另见任务页 |
| 列表 | 统一支持分页、排序、筛选；筛选条件可分享（URL 可复现） |
| 空状态 | 每个列表都需文案 + 主行动按钮 + 说明（见 `§4` 各页“空状态”列） |
| 错误状态 | 需区分：无权限(403)、参数错误(400)、冲突/需重新预览(409)、限流(429)、面板故障(5xx)、面板-数据库不可用、Agent 离线、核心故障、配置未同步 |
| 加载 | 首屏骨架；长任务显示进度与“可离开本页，结果在任务页” |
| 危险操作 | 必须显示影响范围（成员数、节点数、会话是否中断、是否导致断网）+ 二次确认 + 审计 |
| 只读/离线降级 | Agent 离线时相关按钮仍可提交规则，但提示“将在 Agent 恢复后应用”，不得显示为已生效 |
| 敏感信息 | 日志与页面缺省脱敏；复制按钮旁标注“此链接等同于密码” |
| 无障碍/移动端 | 管理员批量页在窄屏退化为卡片列表，逐对象结果可展开（计划 `§3 F12`） |

## 5. 关键用户流程

流程均为“步骤 → 系统行为 → 可见结果/失败”。硬撤权时序见 `§10`，批量的版本与幂等见 `§9`。

### 5.1 创建成员 + 邀请兑换（F01）

1. 管理员在 A7 选择“邀请加入”，设置有效期（如 7 天）、使用次数=1、可绑定订阅（可选）。
2. 系统生成一次性邀请码（高熵，仅展示一次）；列表显示状态 `未使用 / 已使用 / 已过期 / 已撤销`。
3. 受邀者打开链接，输入用户名与密码（满足强度要求）。
4. 系统在**单事务**内：校验邀请仍可兑换 → 原子标记已使用 → 创建成员（默认状态 `active`，无订阅）→ 写审计。
5. 并发/重复兑换：仅一次成功，其余返回统一“邀请不可用”错误（不区分已用/撤销，避免探测）。
6. 结果：成员登录后 M1 显示“暂无可用节点：尚未分配订阅”，管理员 A7 可见新成员待绑定。

### 5.2 订阅创建与成员绑定/切换（F02）

1. 管理员在 A6 新建订阅：名称、说明、节点组（可多选）、配额（不限量或字节）、周期规则、业务时区、默认有效期、客户端模板、已验证可执行的使用限制。
2. 保存即产生**规则版本**；若该订阅已有绑定成员，提示“影响 N 名成员，需预览”（走 `§9`）。
3. 管理员在 A7 为成员绑定订阅：可选择“采用订阅默认有效期”或填写实际有效期。
4. 提交后：业务规则立即在面板生效（授权判定立即可用新规则）；节点分发异步；页面并列展示“规则已生效 / 节点已应用 x/y”。
5. 切换订阅（A→B）：保留成员订阅令牌（链接不变）与当前周期起止时间及已用量；节点集合按新订阅重算；旧订阅独有的节点凭据按策略撤销（默认立即撤销，见 `§10`）；绑定历史记录切换时间与原因。

### 5.3 个人覆盖与恢复继承（F02）

1. 成员详情 → 覆盖面板：仅配额、成员有效期可覆盖（限速未纳入，见 `§15`）。
2. 每个字段显示三列：**实际生效值 / 来源（订阅默认·覆盖）/ 覆盖值**，并显示订阅默认值以便比较。
3. 清空覆盖值 = 恢复继承；UI 明确提示“恢复后将跟随订阅规则变化”。
4. 覆盖不能绕过停用、到期、订阅暂停、节点禁用（保存时若该字段无意义则拒绝并说明原因）。

### 5.4 批量操作（分配/切换订阅、调整有效期、启停、清除覆盖）（F03）

1. 选择操作与目标（勾选成员或“按筛选条件”，后者需展开为显式成员集合）。
2. 请求预览；预览返回影响表（`§9.2`），包含个人覆盖例外、将超额/已超额、将到期成员。
3. 管理员确认；提交携带 `preview_id` 与幂等键。
4. 提交结果：业务变更原子成功；异步分发逐对象进行；结果页显示 逐成员 × 逐节点 的状态。
5. 失败可重试且不重复执行；旧任务不得覆盖新规则（版本更高者胜）。

### 5.5 凭据轮换（F01/F07）

1. 入口：成员详情（管理员）或 M3（成员本人）；范围：单节点 / 该成员全部节点。
2. 确认页列出：受影响节点、将中断的会话数量估算、是否影响订阅链接（默认不影响）。
3. 提交后：旧凭据按策略立即失效（默认 `revoke_immediately`），新凭据写入授权并分发；页面显示分发进度。
4. 订阅链接单独轮换：只阻止再下载，不改变代理凭据（计划 `§3 F07`）。

### 5.6 查看用量与额度（F08）

1. 成员端 M2：显示当前周期 `[start, end)`、业务时区、已用/额度、重置时间、是否超额；无限额时显示“不限量（仍受节点与规则限制）”。
2. 管理员 A9：按成员/节点/周期筛选，展示上下行、是否含协议开销的计量口径标注、网卡流量单列。
3. 账本调整（纠正历史）需填写原因，走审计化“额度调整”，不提供“立即改周期并清零”。

### 5.7 硬撤权（成员停用 / 代理暂停 / 解绑 / 订阅暂停 / 节点禁用）

1. 管理员执行操作 → 确认对话明确：将拒绝新连接并终止已有 TCP/UDP 会话、影响范围、是否可能影响同实例其他成员（共享实例时）。
2. 面板在权限事务提交时记录撤权事件时刻 `revoked_at`，提升该 Agent 的授权版本，写 outbox。
3. Agent 在轮询间隔内获取新快照并应用，回执 `applied_at`。
4. A11 与成员详情显示：`撤销已提交 → 等待下发 → 应用中 → 已生效（用时 x.x s）/ 失败/超时`。
5. 60 秒上限：`applied_at - revoked_at ≤ 60s` 视为达标；超时显示失败并告警（A10），不得显示“已撤销”。

### 5.8 到期与恢复期

1. 到期时间随授权快照下发到 Agent，Agent 本地到点执行，即使面板离线（计划 `§2.2`）。
2. 面板侧同样在到点后更新状态并显示“已到期（本地执行）”。
3. 面板恢复旧备份后进入**恢复协调状态**：普通变更暂停、不向节点推送旧权限，先核对 Agent 已知授权版本与账本，再显式恢复（计划 `§4.3`）。

## 6. 业务状态

状态值用于页面展示与判定；接口字段名以 `api-proposal.md` 为准（待冻结）。

### 6.1 成员账户状态（`account_status`）

| 状态 | 含义 | 能否登录 | 可否有代理权限 | 进入方式 |
| --- | --- | --- | --- | --- |
| `invited` | 已发邀请未兑换 | 否 | 否 | 生成邀请 |
| `active` | 正常 | 是 | 视授权判定 | 兑换/启用 |
| `suspended` | 停用 | 否（现有会话撤销） | 否 | 管理员停用 |
| `archived` | 归档（保留历史与账本） | 否 | 否 | 归档操作 |

### 6.2 代理访问状态（`proxy_access`，与账户状态正交）

| 状态 | 触发 | 效果 | 恢复 |
| --- | --- | --- | --- |
| `enabled` | 判定通过 | 允许 | — |
| `paused_by_admin` | 管理员暂停代理访问 | 硬撤权 | 显式恢复 |
| `expired` | 绑定有效期已过 | 硬撤权（Agent 本地到点执行） | 延长/换绑 |
| `over_quota` | 面板账本判定超额 | 硬撤权 | 下周期开始或提高额度 |
| `no_subscription` | 无绑定/订阅不允访问 | 不授予 | 绑定订阅 |
| `node_unavailable` | 节点禁用/维护/不在授权范围 | 该节点不输出 | 节点恢复 |

“账户停用”“代理访问暂停”“订阅链接撤销”是三个独立状态，不得合并成一个开关（计划 `§2.1`）。

### 6.3 订阅状态（三个独立开关 + 归档）

| 字段 | 取值 | 语义 |
| --- | --- | --- |
| `allow_new_binding` | true/false | 是否允许新绑定/切换进入 |
| `access_paused` | true/false | 暂停现有成员的代理访问（硬撤权） |
| `archived` | true/false | 归档：不可再绑定，保留历史；有绑定需先迁移/解除 |

### 6.4 节点 / 核心实例 / Agent 状态（分层展示）

| 对象 | 状态 | 说明 |
| --- | --- | --- |
| 节点（管理） | `enabled` / `maintenance` / `disabled` | 管理意图，可立即下发 |
| 节点（观测） | `unknown` / `healthy` / `unhealthy` | 探测结果，与配置状态分开显示 |
| 核心实例 | `running` / `stopped` / `failed` / `restarting`，含 `generation` | 每次启动新世代 |
| 配置/授权 | `desired` / `downloaded` / `applied` / `failed` | 期望、已下载、已生效分别展示 |
| Agent | `online` / `offline`（含最后心跳、离线时长） | 离线不显示为“权限已同步” |

“Agent 在线”“进程运行”“端口可达”“代理真实握手”四层必须分别展示（计划 `§3 F11`）。

### 6.5 分发任务与回执状态

| 状态 | 含义 | 是否算达标 |
| --- | --- | --- |
| `pending` | 已入 outbox，未下发 | 否 |
| `dispatched` | 已推送/已进入 Agent 拉取窗口 | 否 |
| `applying` | Agent 正在应用 | 否 |
| `succeeded` | Agent 回执成功且版本匹配 | 是 |
| `failed` | 明确失败（含校验失败） | 否，可重试 |
| `timeout` | 超过 SLA 未回执 | 否，告警 |
| `superseded` | 被更高版本取代 | 否（页面说明原因，不算失败） |

只有 `succeeded` 且回执版本 = 期望版本，才允许显示“已生效”。

### 6.6 上报批次状态（Agent 本地 + 面板侧）

| 状态 | 位置 | 含义 |
| --- | --- | --- |
| `queued` | Agent 本地（事务持久化） | 已落盘待上报 |
| `sending` | Agent | 已发出未确认 |
| `acked` | Agent（可清理） | 收到明确确认 |
| `rejected_permanent` | Agent | 业务拒绝（如载荷/归属错误），保留证据并告警，不计入已确认 |
| `accepted` | 面板 | 已入账（去重后） |
| `duplicate` | 面板 | 幂等重复，返回原结果，不重复入账 |
| `conflict` | 面板 | 同幂等标识异载荷，拒绝并告警 |

### 6.7 邀请状态

`unused` → `used` / `expired` / `revoked`；兑换为原子操作，状态不可回退。

## 7. 订阅规则的继承与覆盖

### 7.1 字段来源矩阵

| 字段 | 订阅级？ | 可个人覆盖？ | 生效时机 | 说明 |
| --- | --- | --- | --- | --- |
| 节点组集合（→ 授权节点） | 是 | 否 | 规则立即，Agent 异步 | 多订阅引用同组时输出按节点去重 |
| 每人配额（字节 / 不限量） | 是 | **是** | 立即（当前周期） | 不低于 0；低于已用量触发超额提示 |
| 成员有效期 | 默认值 | **是** | 立即 | 修改订阅默认值**不改变**已有绑定，需显式批量 |
| 周期起始日 `anchor_day`（1–31） | 是 | 否 | **下一周期** | 见 `§8` |
| 业务时区 `timezone` | 是 | 否 | **下一周期** | IANA 名称，必须显式配置 |
| 客户端配置模板 | 是 | 否 | 立即 | 模板变更使订阅输出缓存失效 |
| 已验证使用限制（如协议/传输约束） | 是 | 否 | 立即 | 未验证的限制不得作为开关上线 |
| 限速 | — | — | — | **未纳入**，待用户选择（`§15`），不做占位开关 |
| 允许新绑定 / 暂停访问 / 归档 | 是 | 否 | 立即 | 三个独立字段（`§6.3`） |

### 7.2 生效值解析顺序（高 → 低）

```text
1. 账户状态（suspended/archived）                → 无权限（不可被覆盖）
2. 代理访问暂停（paused_by_admin）                → 无权限
3. 绑定有效性（无绑定/已到期/未生效）             → 无权限
4. 订阅允许现有成员访问（access_paused/archived） → 无权限
5. 额度（当前周期已用 ≥ 生效配额）                → 无权限（over_quota）
6. 节点级状态（disabled/maintenance）             → 该节点不输出
7. 节点是否属于订阅授权的节点组                  → 该节点不输出
8. 个人覆盖（配额、有效期）                        → 仅替换第 5/3 步使用的值
9. 订阅默认（配额、有效期、周期、模板）            → 兜底
```

第 8 步只替换**值**，不能跳过第 1–7 步的任何限制；这既是安全要求也是 UI 必显示的内容（“该覆盖未绕过停用”）。

### 7.3 UI 展示规则（成员详情 / M1 / M2）

| 展示项 | 内容 |
| --- | --- |
| 生效值 | 当前实际使用的配额与有效期 |
| 来源徽标 | `订阅默认` / `个人覆盖` |
| 被覆盖的默认值 | 仅覆盖时展示，便于对比回滚 |
| 继承变化提示 | “订阅改为 X 后，你的配额将从 A 变为 B（立即生效）” |
| 周期提示 | “新的周期规则将在 2026-11-01 00:00 (Asia/Shanghai) 起生效” |
| 不可覆盖说明 | 节点组、周期、模板等显示“由订阅决定” |

### 7.4 归档与删除

- 有绑定或有历史使用记录的订阅、成员、节点：只能归档/墓碑，不物理删除；账本与去重记录保留（计划 `§4.2`）。
- 归档前的绑定必须迁移或显式解除，页面给出迁移预览。

## 8. 周期、时区与额度

### 8.1 默认算法（建议值，待负责人冻结数值）

- 周期长度：**每月**（不做周/季/自定义为默认；周/自定义若需要，走 `§15` 决策项）。
- 起点：业务时区下每月 **`anchor_day` 日的 00:00:00 本地时间**，`anchor_day ∈ 1..31`。
- 月末裁剪：`d = min(anchor_day, 当月天数)`。因此 `anchor_day=31` 在 2 月自动落在 28/29 日，闰年无需特例。
- 业务时区：默认 `Asia/Shanghai`，但**必须显式写入**订阅与成员周期记录；不从宿主进程时区或浏览器时区隐式推断。
- 存储：`period_start_utc`、`period_end_utc`（右开区间 `[start, end)`），界面按业务时区显示。

### 8.2 边界计算（伪代码，供实现与测试共同引用）

```text
period_start_utc(anchor_day, tz, y, m):
    d = min(anchor_day, days_in_month(y, m))
    local = LocalTime(tz, y, m, d, 00:00:00)
    if local 不存在（DST 跳变跳过该时刻）: 取跳变后的第一个有效瞬间
    if local 出现两次（DST 回拨）:        取较早的绝对瞬间
    return to_utc(local)

next_boundary(boundary_utc, anchor_day, tz):
    # 严格晚于给定边界的第一个 anchor 实例
    candidates = period_start_utc(anchor_day, tz, y, m) for (y,m) in 当前月, 次月, 再次月
    return min(c > boundary_utc)
```

要求：同一算法被用于面板授权、订阅输出、Agent 快照中的 `expires_at`/`quota_reset_at`，并带算法版本号。

### 8.3 规则修改的生效时点

| 变更 | 对当前周期 | 对下一周期 |
| --- | --- | --- |
| 修改订阅 `anchor_day` / `timezone` | 不改：保留当前 `[start,end)` 与已用量 | 从当前 `end` 起使用新规则；下一 `end = next_boundary(end, 新规则)` |
| 直接替换成员绑定的订阅（规则不同） | 同上，保留当前周期 | 同上 |
| 修改配额（订阅默认或个人覆盖） | **立即**应用于当前周期 | 沿用 |
| 连续多次修改周期规则，边界前 | 以边界前**最后一次合法提交**的规则为准 | 同 |
| 边界竞争（提交与边界同一瞬间） | 事务内串行化：以 `boundary_utc` 与提交时刻比较；已过边界则视为对下一周期生效 | — |

- 新周期边界可能因此**缩短或延长**（例：当前 `2026-03-15 ~ 2026-04-15`，改为 `anchor_day=31`，下一周期 `2026-04-15 ~ 2026-04-30`）。UI 预览必须直接显示“下一周期起止”，不允许只显示规则值。
- 不提供“立即改周期并清零”；纠正历史用审计化额度调整（`§5.6`）。

### 8.4 额度、超额与恢复

| 场景 | 行为 |
| --- | --- |
| 提高配额 | 立即生效；若此前 `over_quota`，在同一事务内恢复代理访问并下发 |
| 下调配额至低于已用量 | 提交前提示“将立即超额并撤权”，需确认；确认后立即超额撤权 |
| 达到/超过配额 | 面板在**账本提交事务**内判定，提交后启动撤权链路；60 秒计时从该提交起（计划 `§2.2`） |
| 新周期开始 | 已用量“按周期归属”自然归零（不删历史）；`over_quota` 自动重算，未超额则恢复权限 |
| 离线期间超额 | 不承诺跨节点全局额度硬截止（计划 `§3 F08`）；页面显示“可能已超额（待同步）” |

### 8.5 跨周期补报与归属

- 批次按**采样区间发生时间**归属周期；接收时间单独审计。
- 区间完全落在已关闭周期：记入该历史周期账本；**不追溯触发**已结束周期的撤权，仅记录并在 A9 标注“历史周期更正”。
- 区间跨越周期边界：按**区间时长比例**分摊到两侧（`estimated=true`, `boundary_split=true`），并显示为估计值；不声称精确还原每字节时刻（计划 `§3 F09`）。
- 时钟漂移/异常时间：隔离为待人工确认状态，不擅自挪到当前周期。
- 停用/解绑/轮换凭据后的合法历史数据：按历史映射入账，不以“当前无授权”拒收。

### 8.6 批量调整周期相关字段的产品约束

- 批量“调整有效期”≠ 修改周期规则；两者在 UI 上分开，不合并按钮。
- 批量修改周期规则（订阅级）必须预览：显示每名成员“当前周期起止 / 新规则下下一周期起止 / 是否跨边界”。
- 批量结果中周期变更只改变 `next_rule`，当前周期与已用量不变，页面用徽标 `下一周期生效` 明确标注。

## 9. 批量预览、提交与结果

### 9.1 流程

```text
选择操作 → 解析目标集合 → 预览(preview) → 确认 → 提交(commit, 幂等键) → 异步分发 → 逐对象结果 → 可选重试
```

### 9.2 预览必须包含

| 内容 | 说明 |
| --- | --- |
| 目标成员清单（ID、名称） | 筛选条件需先展开为显式集合，展示总数 |
| 每人前值 → 后值 | 配额、有效期、订阅、覆盖是否被清除 |
| 个人覆盖例外 | 哪些人因覆盖不会被改变、哪些覆盖将被清除 |
| 后果预测 | 将超额、将到期、将失去全部节点、将触发断线（共享实例） |
| 节点影响 | 受影响节点数与 Agent 数、是否需重启实例 |
| 版本戳 | `rules_version`、成员集合摘要 `member_set_digest`、`preview_id`、过期时间 |
| 不可执行项 | 因权限/最后管理员保护/无订阅等被拒绝的对象及原因 |

### 9.3 提交时的校验（不同步锁死）

1. `preview_id` 必须存在且未过期（建议 TTL 10 分钟）。
2. `rules_version` / `member_set_digest` 变化 → 409 `PREVIEW_STALE`，要求重新预览。
3. 已用量等动态值在提交时重算：若**结论**（谁超额、谁失去权限）未变，仅数值变化 → 允许提交并记录提示；若结论改变 → 409 `PREVIEW_CONCLUSION_CHANGED`，要求重新确认。
4. 幂等键：同键同指纹 → 返回原结果；同键异指纹 → 409 拒绝（见 `§5.4`、`acceptance.md` AC-BATCH）。
5. 业务规则变更 + 任务/outbox + 审计在**同一 PostgreSQL 事务**提交。

### 9.4 结果展示

- 汇总：`已保存规则 12 项 · 节点下发 9/12 成功 · 3 待重试`。
- 明细：成员 × 节点 × 状态（`pending/applying/succeeded/failed/timeout/superseded`）+ 错误原因 + 重试按钮。
- 禁止把汇总显示为“全部生效”；禁止只给一个成功 toast。
- 重试只针对失败/超时项，且带版本检查，旧任务不覆盖新规则。

## 10. 硬撤权与到期（产品视角）

| 项 | 规格 |
| --- | --- |
| 触发集合 | 成员停用、代理访问暂停、解绑/移除节点授权、订阅暂停、节点禁用、到期、超额、旧凭据撤销；**单独轮换订阅链接不算代理硬撤权** |
| 达标定义 | 自面板撤权事务提交起 60 秒内：拒绝新连接 **且** 终止对应凭据已有 TCP/UDP 会话 |
| 计时起点 | 面板事务提交时刻（`revoked_at`），非流量越界时刻 |
| 计时终点 | Agent 回执 `applied_at` 且版本匹配；页面显示实测用时 |
| 超时处理 | 显示“未完成”+ 告警 + 事件，不得显示“已撤销” |
| 离线例外 | 离线期间新产生的撤权不承诺 60 秒；恢复通信并取得最新授权后 60 秒内完成；页面显示“待同步 / 离线时长” |
| 已知到期 | 不受离线例外覆盖：Agent 本地到点执行，面板离线也需在到期后 60 秒内达标 |
| 共享实例 | 若核心 API 只能拒绝新连接，须按“停止/按最新授权重建受影响实例”兜底；节点启用前必须明确该策略与影响范围 |
| 时钟异常 | 告警并进入既定安全处理流程，不得默默延长权限 |

配置项提案（待冻结）：节点级 `revocation_strategy ∈ {api_only, api_and_verify, instance_restart}`，启用前展示影响；`api_only` 若实测无法终止旧连接，则不得用于验收通过的节点。

## 11. 离线与降级（界面语义）

| 故障 | 界面表现 | 禁止 |
| --- | --- | --- |
| Agent 离线 | 显示最后心跳、离线时长、“规则待下发”；提交仍可成功（规则已保存） | 显示“权限已同步” |
| PostgreSQL 不可用 | 所有写入显示“未确认/失败”，可重试；不返回伪成功 | 用缓存伪造提交成功 |
| Redis 不可用 | 授权回查 PG；登录限流降级（本地受限/拒绝） | 无限放行；把 Redis 当唯一权威 |
| 核心进程故障 | 区分“进程崩溃/配置未同步/端口不可达”，给重建入口 | 自动放宽权限 |
| 面板回退旧备份 | 进入恢复协调模式横幅：只读 + 待核对 | 向节点推送旧授权 |
| 上报积压/磁盘告警 | A10 事件 + Agent 卡片显示队列长度 | 静默丢弃未确认数据 |

## 12. 保留、删除与审计

- 成员/节点/订阅删除 = 归档或墓碑；保留合法历史上报所需映射（成员×节点历史凭据映射）。
- 审计事件至少覆盖：登录/登出、密码重置、会话撤销、邀请创建与兑换、成员启停与归档、订阅变更与归档、绑定/切换、覆盖增删、批量预览与提交、凭据轮换、额度调整、节点与核心实例变更、配置/授权下发与回执、升级与回滚、恢复模式进出、告警确认。
- 审计不记录秘密值（令牌、密码、私钥、完整凭据）。

## 13. 协议与客户端适配边界（提案，未经用户确认）

### 13.1 分层边界

| 层 | 归属 | 允许做的事 | 禁止的事 |
| --- | --- | --- | --- |
| 面板 | 面板 Go 模块 | 维护节点元数据与结构化协议参数；按声明式 schema 校验必填/类型/取值域；计算授权；生成快照 | 解析或改写 Xray JSON 语义；按协议猜测“客户端一定兼容” |

| Agent | `internal/agent/xray` | 把参数块映射为官方 Xray 配置、调用本机管理 API、校验、应用、回执 | 接受未声明参数；执行任意命令 |

### 13.2 能力矩阵（模板，需用户确认后填实）

| 协议 | 传输 | 安全 | 建议状态 | 备注 |
| --- | --- | --- | --- | --- |

| 其他协议/传输/安全组合 | — | — | **未确认，不列入支持声明** | 需用户提供实际清单 |

规则：
- 未在矩阵中标记“已验证”的组合，节点保存时拒绝或标记 `未验证` 并禁止用于验收通过声明。
